# Creative Project Layout Ideas

## Option 1: Bento Grid (Apple-Style)
**Inspiration:** Apple.com, Linear.app

**Layout:**
```
┌─────────────────┬──────────┐
│                 │          │
│   Featured      │  Card 2  │
│   Project 1     │          │
│   (Large)       ├──────────┤
│                 │          │
│                 │  Card 3  │
├─────────┬───────┴──────────┤
│         │                  │
│ Card 4  │    Card 5        │
│         │    (Wide)        │
├─────────┴──────────────────┤
│                            │
│       Card 6 (Full)        │
└────────────────────────────┘
```

**Characteristics:**
- Mixed sizes: One hero card, various sized cards
- Asymmetric, organic layout
- Different aspect ratios create visual interest
- Latest/most important projects get larger cards

## Option 2: Diagonal Stagger Layout
**Inspiration:** Stripe.com, Figma.com

**Layout:**
```
    ┌──────────┐
    │ Card 1   │
    └──────────┘
          ┌──────────┐
          │ Card 2   │
          └──────────┘
    ┌──────────┐
    │ Card 3   │
    └──────────┘
          ┌──────────┐
          │ Card 4   │
          └──────────┘
```

**Characteristics:**
- Cards positioned diagonally/offset
- Creates flowing, dynamic rhythm
- Natural scrolling motion
- Great for storytelling progression
- Can alternate left-right alignment

## Option 3: Featured + Masonry Grid
**Inspiration:** Awwwards.com, Behance.com

**Layout:**
```
┌────────────────────────────┐
│                            │
│    Featured Project 1      │
│    (Hero with hover exp.)  │
│                            │
└────────────────────────────┘

┌──────────┬──────────┬──────────┐
│          │          │          │
│ Card 2   │ Card 3   │ Card 4   │
│ (Tall)   │ (Short)  │ (Medium) │
│          ├──────────┤          │
│          │ Card 5   │          │
└──────────┴──────────┴──────────┘
```

**Characteristics:**
- One large hero card for latest/best project
- Remaining projects in Pinterest-style masonry
- Variable heights based on content
- More breathing room

## Option 4: Horizontal Scroll Carousel
**Inspiration:** Netflix.com, Apple TV+

**Layout:**
```
← ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐ →
  │Card 1│ │Card 2│ │Card 3│ │Card 4│
  └──────┘ └──────┘ └──────┘ └──────┘
                                   ...scroll
```

**Characteristics:**
- Horizontal scrolling row
- Cards slightly tilted/3D on hover
- Keeps page shorter
- Fun, interactive experience
- Can show more projects without overwhelming

---

## Option 5: Overlapping Cards with Depth
**Inspiration:** Pitch.com, Framer.com

**Layout:**
```
        ┌────────────┐
        │  Card 1    │ (Front)
    ┌───┤            ├───┐
    │   └────────────┘   │
    │   Card 2 (Behind)  │
┌───┤                    ├───┐
│   └────────────────────┘   │
│   Card 3 (Further Back)    │
└────────────────────────────┘
```

**Characteristics:**
- Cards stacked with depth/parallax effect
- Hover brings cards forward
- Creates 3D layered feeling
- Dramatic, modern aesthetic
- Emphasizes hierarchy
